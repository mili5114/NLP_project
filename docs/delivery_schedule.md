## 已完成的最前置准备

- 研究范围、四条件和唯一职责已在两份根目录方案中明确。
- `docs/interfaces.md`：反馈函数、事件、在线日志、离线评分边界。
- `fixtures/`：独立开发所需合成样例，不需要先跑真实模型。

这些准备无需再让 A 从零定义一遍。认领后各自按接口开工；与真实官方实现的接线仍由 A 完成。

## 无需等待对方的第一步

- A 直接读原始课程配置、获取固定上游代码并搭环境，用 stub feedback 实现 runner。
- B 直接读研究方案方法部分，用 feedback fixture 实现 C/D，不用等 GPU。
- C 直接用 synthetic episode 与独立参考文件实现 scorer/auditor，不用等 A 的真实结果。

等待关系只有：真实DEV候选需要真实基线；EVAL需要冻结包；最终结果需要真实EVAL。前面工具开发可以并行。合成数据不计入研究结果。当前未完成真实上游代码适配、模型安装/GPU pilot、评分脚本和正式运行，不将接口文档误当作可运行平台。
